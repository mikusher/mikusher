# Luís Amílcar Tavares (@mikusher)

**Application Security Engineer** working across secure software engineering, backend development, cloud security, DevSecOps and automation.

I focus on validating security risks against real code paths, improving engineering controls and turning security analysis into practical changes. My repositories include original projects, experiments, educational material and forks kept for reference.

## Areas of focus

- **Application Security:** secure code review, SAST/DAST evidence, vulnerability validation and threat modeling.
- **Secure engineering:** backend architecture, data handling, authorization boundaries and reliability.
- **DevSecOps:** CI/CD, security automation, dependency hygiene and supply-chain controls.
- **Research and learning:** reproducible experiments, benchmarks and security-oriented tooling.

## How I approach engineering

- Prefer evidence of reachability and exploitability over unvalidated scanner alerts.
- Make security assumptions, trust boundaries and residual risks explicit.
- Keep changes reviewable, testable and proportional to the problem.
- Treat production readiness as a verified property, not a label.
